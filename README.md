# Interactive HTML BOM plugin for KiCad

![icon](https://i.imgur.com/js4kDOn.png)

This plugin generates a convenient Bill of Materials (BOM) listing with the
ability to visually correlate and easily search for components and their placements
on the PCB. It is particularly useful when hand-soldering a prototype, as it allows
users to quickly find locations of components groups on the board. It is also possible
to reverse lookup the component group by clicking on a footprint on the board drawing.

The plugin reads PCB data from a running KiCad through the
[KiCad IPC API](https://dev-docs.kicad.org/en/apis-and-binding/ipc-api/) (kicad-python) and
renders silkscreen, fab layer, footprint pads, text, and drawings. BOM table fields and grouping is fully configurable,
additional columns, such as a manufacturer ID, can be added in Schematic editor and
imported either through the netlist file, XML file generated by Eeschema's internal
BOM tool, or from board file itself.

There is an option to include tracks/zones data as well as netlist information allowing
dynamic highlight of nets on the board.

For full description of functionality see [wiki](https://github.com/openscopeproject/InteractiveHtmlBom/wiki).

Generated html page is fully self contained, doesn't need internet connection to work
and can be packaged with documentation of your project or hosted anywhere on the web.

[A demo is worth a thousand words.](https://openscopeproject.org/InteractiveHtmlBomDemo/)

## Installation and Usage

See [project wiki](https://github.com/openscopeproject/InteractiveHtmlBom/wiki/Installation) for instructions.

### KiCad (IPC API)

The legacy SWIG `pcbnew` Python module is not used anymore (KiCad removes it in
version 11). KiCad boards are read over the IPC API instead:

- KiCad 9.0.3 or newer is required. Enable the API server in
  *Preferences > Plugins > Enable KiCad API*.
- KiCad loads the plugin from `InteractiveHtmlBom/plugin.json` and installs the
  Python dependencies listed in `InteractiveHtmlBom/requirements.txt` into a
  plugin virtual environment. For a manual install, copy or symlink the
  `InteractiveHtmlBom` folder into KiCad's `plugins` directory.
- The settings dialog needs wxPython in the plugin's Python. On Linux install it
  with the system package manager (for example `python3-wxgtk4.0`). If it can not
  be imported, the plugin reports the import error in KiCad's notifications
  instead of generating anything.
- Command line: `generate_interactive_bom board.kicad_pcb` connects to the running
  KiCad, so the board must be open in the PCB editor. Run it without a file to use
  whatever board is open. Only KiCad is supported; the EasyEDA, Eagle/Fusion360
  and generic json importers of the upstream project have been removed.
- Known gaps compared to the old pcbnew backend, until the IPC API exposes the
  needed data: dimensions and barcodes are not drawn, knockout text is drawn as
  regular text, castellated holes are not clipped to the board edge, and the
  KiCad variant must be chosen with `--kicad-variant` (needs KiCad 10.0.7+).
